# 饱和曲线轮廓与联合预测界

本页说明 `analysis_data.curve` 的数学口径。所有运行比例、方差、规模和成本
均为合成资料；模块只读取历史汇总行，不启动训练、不调用学习模型，也不使用
模型权重或真实投资资料。

## 模型与加权目标

对规模 `n`，先用资料中的 `scale` 归一：

```
f(n) = a - b * exp(-k * n / scale)
0 <= b <= a <= 1
k > 0，且 k 只取资料声明并按升序排列的 k_grid
```

`k_grid` 本身就是搜索域。输出中的 `grid_best` 是网格上的最佳解，不是对
连续 k 做局部优化后冒称的“全局最优”。

每一行运行保留自己的 `run_id`、规模、比例和已知测量方差 `variance`。目标
为逐行加权最小二乘：

```
Q(k,a,b) = sum_rows (y - a + b*exp(-k*n/scale))^2 / variance
```

同规模多行不会被合并后丢弃，也不会按结果好坏删种子。`sum_w`、`sum_wt`、
`sum_wt2`、`sum_wy`、`sum_wty`、`sum_wy2` 随每个网格点输出，可直接复算目标。

## 固定 k 的有界二次子问题

令 `t = exp(-k*n/scale)`，则

```
Q = s0*a^2 + s2*b^2 - 2*s1*a*b - 2*y0*a + 2*y1*b + c
```

对固定 k 这是 (a,b) 上的凸二次目标。实现枚举三角形
`b>=0, b<=a, a<=1` 的三个顶点、三条边上的最小点，以及正定且可行时的
无约束内点，因此能处理：

* 最优参数贴边（例如 `a=1` 或 `b=0`）；
* 所有 `t` 相同导致的共线设计（`rank=1`，a、b 不可分别识别）；
* 边或整个目标接近平坦时的非唯一最小点（`non_unique_minimizer`）。

每个网格点都输出目标、参数、三条约束的残差、最大违反量、活跃约束和设计
秩。目标同分时按配置的 `tie_tolerance` 判断，并优先较小 k，其后按 (a,b)
字典序选择；报告同时标记非唯一性，不借目标容差放大识别精度。

## 轮廓接受集合

先取所有网格点各自最小目标中的全局最小值 `Qmin`，调用者给出的 `cutoff`
定义接受阈值：

```
Q_k,min <= Qmin + cutoff
```

接受的 k 原样保留。`profile.segments` 只按网格相邻关系分组，因此断裂的
接受域会显示为多个段，不会被强行连成一个区间。

`cutoff` 是调用者依据已知方差给出的高斯近似。输出是**模型条件轮廓集合**，
不自动具有有限样本覆盖率，也不是置信区间的自动保证。

## 整个参数集合上的联合预测界

设

```
S = { (a,b,k) : 0<=b<=a<=1, k 在声明的接受网格点,
                 Q(k,a,b) <= Qmin + cutoff }
```

对候选规模 `candidate_n`，预测下界和上界是

```
min_{S} f(candidate_n),  max_{S} f(candidate_n)
```

而不是只把每个 k 的最佳 (a,b) 连成一条线。对每个接受的 k，在
`三角形 ∩ {Q(k,a,b)<=阈值}` 上求线性目标的极值：

* 正定目标：枚举三角形顶点、三角形边与椭圆边界的交点，以及目标方向与
  椭圆相切的点；
* 退化目标：退化为平行带与三角形的交多边形，枚举相关直线的两两交点。

每个极值点都检查三角形可行性、目标是否不超过阈值，并输出
`feasibility_check`。如果任一子问题没有完成检查，正式区间改用三角形隐含
的保守区间 `[0,1]` 并标记 `status=incomplete`，不会先把过窄数值当作正式
结论。

预测增益也在同一个 S 上直接优化差值：

```
min_{S} [f(candidate_n) - f(baseline_n)]
max_{S} [f(candidate_n) - f(baseline_n)]
```

因为 a 在差值中抵消，增益为 `b*(exp(-k*baseline_n/scale) -
exp(-k*candidate_n/scale))`，但仍需在同一个受约束 S 中联合求界。输出中的
`independent_subtraction_diagnostic` 只用于展示“两个独立预测区间相减”会
得到更宽且不成立的区间，不是正式增益界。

候选规模不小于 baseline；新增样本数为 `candidate-baseline`，费用按

```
cost = fixed + per_sample * (candidate_n - baseline_n)
```

计算，相等时为 0。候选表并列给出新增量、费用、预测区间、增益区间，以及
“是否仍无法排除零增益”和候选两两比较。两两比较同样在 S 上直接优化
`f(n_i)-f(n_j)`，区间跨 0 时标记 `indistinguishable`。这些输出不构成投资
建议或确定收益承诺。

## 可运行例子

```sh
# 网格拟合、轮廓分段、候选费用/增益表
python -m analysis_data.cli profile data/normal.json

# 密集 (a,b) 穷举 vs 解析包络 vs “只连最佳曲线”的反例
python -m analysis_data.cli crosscheck data/flat-platform.json \
  --candidate-n 2500 --steps 200
```

预期要点：

| 资料 | 观察 |
| --- | --- |
| `data/normal.json` | 网格最佳 k=1；只有 k=1 进入 profile；增益下界为正 |
| `data/flat-platform.json` | 所有 k 目标同为 0，接受域完整；最佳 (a,b)=(0.8,0)，b=0 贴边；只连最佳曲线的候选预测宽为 0，而完整 S 的包络约 [0.786, 0.834]，且无法排除零增益 |
| `data/boundary-a.json` | 最佳 a=1、b=0，活跃约束 `a<=1` 与 `-b<=0`；预测上界为 1 |
| `data/single-scale.json` | 所有 k 的设计秩为 1（规模点全相同），a/b 共线；只连最佳曲线给 [0.595,0.595]，完整 S 给更宽的包络 |
| `data/disconnected-profile.json` | 接受 k 为 [0.5,1] 与 [4,8] 两段，中间 k=2 被拒绝；profile 保持断裂 |

`tests/test_curve.py` 还会用密集三角形成交网格交叉检查解析预测包络，并验证
联合增益界严格位于“两个独立区间相减”的诊断区间之内。

## 读结果时的边界

* `grid_best` 仅相对声明网格；网格外的 k 没有被搜索。
* profile 接受与预测界都以给定模型和给定的已知方差为前提；模型设定错误
  不在这些区间内表达。
* `cutoff` 不是自动的 95% 覆盖率；它只是调用者提供的高斯近似阈值。
* 若 `gain_interval.lower` 为 0 或区间跨 0，当前资料无法区分扩大采集与没有
  可辨识增益；不应把它包装成确定收益。若下界只是极小正数（例如曲线已接近
  饱和、候选与 baseline 的差距只剩浮点级别的预测差），也应按实际决策尺度
  视为不可区分，而不是当作确定收益。
* 同一 k 内接近平坦或共线时，参数区间可能很宽，这是识别性诊断的一部分，
  不是数值失败。
